
# GTS Portfolio Website

A personal developer portfolio website built to showcase my background, skills, projects, and journey into software engineering.

This project represents my practical experience with frontend web development, using HTML, CSS, and JavaScript to create a modern, responsive, and interactive website.

🌐 **Live Website:** https://george-temidayo.netlify.app/


## 🖼️ Preview

![GTS Portfolio Homepage](portfolio-preview.png)



## ✨ Features

- **Responsive Design:** Adapts to different screen sizes, including desktops, tablets, and mobile phones.
- **Modern Dark Theme:** Features a clean black and gold design.
- **About Me Section:** Introduces me and my development journey.
- **Skills Section:** Showcases my current technical skills.
- **Featured Projects:** Highlights selected projects I've worked on.
- **Contact Form:** Allows visitors to send messages.
- **Scroll Animations:** Adds smooth reveal effects as visitors navigate the website.
- **Mobile Navigation:** Provides a navigation menu suitable for smaller screens.
- **Back to Top Button:** Makes it easier to return to the top of the page.
- **Social Links:** Provides access to my GitHub profile.


## 🛠️ Technologies Used

- **HTML5:** Used to structure the content and sections of the website.
- **CSS3:** Used for styling, responsive layouts, animations, and visual effects.
- **JavaScript:** Used to add interactive functionality, including mobile navigation, scroll animations, and the Back to Top button.
- **Google Apps Script:** Used to handle email notifications from the contact form.
- **Google Forms & Google Sheets:** Used to collect and store contact form submissions.
- **Netlify:** Used to host and deploy the website.
- **GitHub:** Used for source code management and version control.

While building this project, I gained practical experience in:

- Structuring multi-section websites using semantic HTML.
